# Лабораторная работа № 5. Вариант № 2

**Тема:** Перегрузка операторов. Дружественные функции.  
**Уровень:** Повышенный.

## Задание

Разработать класс `Matrix` для работы с матрицами. Реализовать умножение и транспонирование, перегрузку арифметических операторов и операторов сравнения, составное присваивание, инкремент и декремент, доступ через `[]` и `()`, явное преобразование типов, дружественные функции и обработку исключений.

## Реализация

Класс содержит закрытые данные, конструкторы, деструктор, геттеры, безопасное копирование и проверку размеров. Умножение выполняется по правилам матричной алгебры; деление `A / B` определено как `A * inverse(B)` (при существовании обратной матрицы). Операторы порядка используют лексикографическое сравнение элементов с учётом размеров. Операторы `++` и `--` изменяют каждый элемент на единицу. Преобразование к `double` возвращает норму Фробениуса.

В `main.cpp` показаны основные операции, работа с прямоугольными матрицами и обработка ошибок.

## Запуск

Добавить `Matrix.h`, `Matrix.cpp` и `main.cpp` в консольный проект C++ (Visual Studio). Запустить программу комбинацией **Ctrl + F5**. Вводить данные не требуется.
